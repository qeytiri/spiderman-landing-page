# 🕷️ Spider-Man Landing Page

Kinematyczna strona poświęcona Spider-Manowi w języku polskim — zbudowana z React, Vite i Framer Motion.

## Stack

- **React + Vite** + TypeScript
- **Framer Motion** — animacje scroll
- **Tailwind CSS** + shadcn/ui
- **Oswald** (Google Fonts)

## Sekcje

- **Hero** — ciemne tło NYC z paralaksą
- **Geneza** — historia Petera Parkera
- **Moce** — poziomy scroll z kartami
- **Kostiumy** — selektor z animacją 3D
- **Oś czasu** — interaktywna chronologia
- **Cytaty** — kultowe słowa Spider-Mana
- **Złoczyńcy** — Zielony Goblin, Dr Octopus, Venom

## Uruchomienie

```bash
pnpm install
pnpm --filter @workspace/spiderman run dev
```
